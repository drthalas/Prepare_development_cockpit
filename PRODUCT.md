# Prepare Development Cockpit

## Product

Prepare Development Cockpit — SaaS-инструмент для подготовки проекта к реализации: от идеи и уточняющих вопросов до спецификации, дорожной карты, задач и экспорта.

## Primary User

Пользователь хочет быстро превратить идею проекта в структурированную спецификацию, дорожную карту и набор задач для реализации.

## Design Principles

- Спокойный рабочий SaaS-интерфейс.
- Минимум технического шума.
- Понятные действия.
- Сильная визуальная иерархия.
- Карточки должны выглядеть как осмысленные блоки, а не сырые таблицы.
- Все кликабельные элементы должны быть настоящими действиями.
- Fake/no-op links запрещены.
- Важные статусы должны быть визуально очевидны.
- Пустые состояния должны объяснять следующий шаг.

## Visual Direction

- Light UI.
- White/light-gray background.
- Clean cards.
- Subtle borders.
- Moderate radius.
- Restrained green accent.
- Readable typography.
- Consistent section spacing.
- Hover/focus states for interactive rows.

## Anti-Patterns

- Сплошной текст.
- Слишком тонкие разделители без структуры.
- Технические labels вроде raw, json, markdown, unknown, undefined.
- Кнопки, которые ничего не делают.
- Дублирующие CTA.
- Большие пустые зоны без смысла.
- Разные размеры шрифтов без иерархии.
- Перегруженные панели.
